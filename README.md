# Personal Log

A personal logging and tracking web application built with Svelte and TypeScript, designed to keep track of media, games, and personal notes with a clean, dark-themed interface.

## Tech Stack

* **Framework:** [Svelte](https://svelte.dev/)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Build Tool:** Vite
* **Hosting / Deployment:** Vercel

```text
log/
